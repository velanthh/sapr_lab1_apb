# APB Slave — лабораторная работа № 1

## О репозитории

Репозиторий содержит SystemVerilog-модель APB-slave, модель APB-master и тестовый модуль для проверки операций чтения и записи.

## Состав проекта

- `apb_slave.sv` — APB-slave с четырьмя 32-битными регистрами;
- `apb_master.sv` — модель APB-master, выполняющая операции чтения и записи;
- `tb_apb.sv` — тестовый модуль, формирующий тактовый сигнал, сброс и последовательность проверок;
- `run.do` — сценарий запуска симуляции в ModelSim.

## Карта регистров

Базовый адрес устройства: `0x70000000`.

| Смещение | Назначение |
|----------|------------|
| `0x00` | номер по списку |
| `0x04` | дата выполнения лабораторной работы |
| `0x08` | первые четыре символа фамилии |
| `0x0C` | первые четыре символа имени |

APB-slave поддерживает операции чтения и записи. При обращении по недопустимому или невыровненному адресу устанавливается сигнал `PSLVERR`.

Тестовый модуль проверяет:

- значения регистров после сброса;
- запись и последующее чтение четырёх регистров;
- обработку недопустимых адресов;
- очистку регистров при повторном сбросе.
