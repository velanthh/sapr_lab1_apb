## Преобразование 32-битных слов

`python word32.py 15` выводит `0x0000000F`.
После слияния ветки с доработкой команда `python word32.py --ascii Huda`
выводит `0x48756461`. Первый символ занимает старший байт слова.

## Симуляция APB

Требуются Python 3 и Icarus Verilog. Команды `iverilog` и `vvp`
должны быть доступны через `PATH`. Запуск из корня репозитория:

```text
python run_sim.py
```

Мастер `apb_master.sv` выполняет чтение и запись по APB.
Слейв `apb_slave.sv` принимает операции по базовому адресу
`0x70000000`. Верхний модуль `tb_apb.sv` связывает модули, формирует
тактирование и сброс и сравнивает полученные данные с ожидаемыми.

| Смещение | Данные | Слово |
| --- | --- | --- |
| `0x0` | Номер по списку, 15 | `0x0000000F` |
| `0x4` | Дата 11.11.2026, BCD в порядке ДДММГГГГ | `0x11112026` |
| `0x8` | Первые четыре символа фамилии, `Huda` | `0x48756461` |
| `0xC` | Первые четыре символа имени, `Yusu` | `0x59757375` |

Тест проверяет обратное чтение всех четырёх слов, недопустимые адреса
и очистку регистров при сбросе. Симуляция печатает операции и строку
`PASS` при успешной проверке.

## Версия для пункта 8

Тег `apb-point8` отмечает версию, где запись младшего бита 0 даёт
`0xAAAAAAAA`, а запись младшего бита 1 даёт `0x55555555`.
Запуск этой версии в отдельном рабочем каталоге:

```text
git worktree add --detach ../sapr-lab1-point8 apb-point8
cd ../sapr-lab1-point8
python run_sim.py
```

Тег `lab1-final` отмечает итоговую версию для пункта 9.
