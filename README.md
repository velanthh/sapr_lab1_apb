# APB Slave — лабораторная работа № 1

## О репозитории

Репозиторий содержит SystemVerilog-модель APB-slave и тестовый модуль, выполняющий роль APB-master.

## Состав проекта

- `apb_slave.sv` — APB-slave с четырьмя 32-битными регистрами;
- `tb_apb_slave.sv` — тестовый модуль `TB` с операциями чтения и записи;
- `run.do` — сценарий запуска в ModelSim.

## Карта регистров

Базовый адрес устройства: `0x70000000`.

| Смещение | Назначение | Тестовое значение |
|---|---|---|
| `0x00` | номер по списку | `0x0000000F` |
| `0x04` | дата выполнения | `0x11112026` |
| `0x08` | первые четыре символа фамилии | `0x48756461` |
| `0x0C` | первые четыре символа имени | `0x59757375` |

При обращении по недопустимому адресу устанавливается сигнал `PSLVERR`.

## Запуск в ModelSim

В окне Transcript выполнить:

```tcl
do run.do
```
