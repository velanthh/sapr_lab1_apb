## Симуляция APB

Требуются Python 3 и Icarus Verilog. Команды `iverilog` и `vvp`
должны быть доступны через `PATH`. Запуск из корня репозитория:

```text
python run_sim.py
```

Мастер `apb_master.sv` выполняет чтение и запись по APB.
Слейв `apb_slave.sv` принимает операции по базовому адресу
`0x70000000`. Верхний модуль `tb_apb.sv` связывает модули, формирует
тактирование и сброс и сравнивает полученные данные с ожидаемыми.

В пункте 8 запись младшего бита 0 даёт `0xAAAAAAAA`, а запись
младшего бита 1 даёт `0x55555555`. Тест проверяет оба значения
после записи и после простоя, ошибки адресации и повторную запись.
Симуляция печатает операции и строку `PASS` при успешной проверке.
